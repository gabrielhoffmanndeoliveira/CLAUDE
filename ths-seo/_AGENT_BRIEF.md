# Brief for THS SEO content agents

The House Supplier (thehousesupplier.com) is a Shopify store selling plumbing and HVAC supplies, shipping from Seattle, WA (shipping only, no local pickup). Organic search is weak (Ahrefs Domain Rating 0.7). Several agents prepare SEO content in parallel.

## Rules for every agent
- Your job is to WRITE FILES for the owner to review. Do NOT change the store: never run a Shopify mutation, never publish, never contact anyone. Do not run git. Do not include customer data.
- Tools: load with ToolSearch, query "select:mcp__Shopify__graphql_query,mcp__Shopify__run-analytics-query,WebSearch". If the Shopify tools cannot be loaded, say so in your first line and stop. Direct page fetches may be blocked; rely on search snippets and record anything you could not confirm in the review file.
- Content: US English. Facts only from (a) the store's own product data (titles, custom.specifications and other metafields) and (b) manufacturer documentation. Never invent a spec. No claims about price, stock, delivery time, free shipping, warranty length or authorized-dealer status. No superlatives, no marketing filler. Anything unconfirmed goes in the review file, not in the content.
- Files go in /home/user/CLAUDE/ths-seo/, written with Python's csv module (QUOTE_ALL, UTF-8). Save your work to disk early and often: write the files after every 5-10 items, so that an interruption does not lose the work. If your output files already exist when you start, read them and continue from where they stop instead of starting over.
- Final report: short. Files written, counts, and what the owner should know.

## Collection content task
1. Find collections with graphql_query, e.g. collections(first:50, query:"title:*KEYWORD*") { nodes { id handle title descriptionHtml seo { title description } productsCount { count } } }, using the keywords for your family.
2. Pick the 18 that matter most: the most products, with products in stock (sample: products(first:20) { nodes { vendor title totalInventory } }). Read enough product titles to know what each collection holds. Skip pipe and tube collections.
3. For each write: SEO title (60 characters max, starting with the phrase people search, no " | The House Supplier" suffix); meta description (155 characters max); Body HTML = intro of 100-160 words in <p>; <h2>How to choose</h2> with a <ul> of 3-5 selection points specific to the category; <h2>Common questions</h2> with 3 questions (<h3>) and answers (<p>); a closing <p> linking to 3-5 related collections that exist (<a href="/collections/HANDLE">, handles verified). If the collection already has 120+ words, keep its facts and improve it.
4. Files: Collections_<family>_content_matrixify.csv with columns ID, Handle, Command (UPDATE), Body HTML, Metafield: title_tag [string], Metafield: description_tag [string]; Collections_<family>_content_ROLLBACK_matrixify.csv (same columns, current values); REVIEW_collections_<family>_notes.csv (Handle, Target query, Words, Verify notes, Sources). Check lengths with a script.
5. Report also up to 5 collections that should exist but do not, with the rule and the in-stock count.

## Product description task

Fetch in batches of 10: productVariants(first:10, query:"sku:A OR sku:B") { nodes { sku product { id handle title status totalInventory tags descriptionHtml specs: metafield(namespace:"custom", key:"specifications") { value } disc: metafield(namespace:"custom", key:"discontinued") { value } } } }. Keep ACTIVE products with stock.
2. Preserve existing structured blocks. Some descriptions contain sections headed <h3>Full Specifications</h3>, <h3>Documents &amp; Downloads</h3>, <h3>Compatible Accessories</h3>, or <h3>Specifications</h3>, <h3>Documents</h3>, or a "See also" links paragraph. Keep every such block exactly as it is, after your new text. Rewrite only the part before the first of them.

4. New leading part: opening <p> of 60-100 words with the model number in the first sentence and the specs that identify the product; <h3>Key Features</h3> with a <ul> of 5-7 items; one more <h3> section suited to the category (Applications, Compatible Systems, or What Is Included); <h3>Before You Order</h3> with a <ul> of what the buyer must check. Compatibility and "replaces" statements must come from manufacturer documentation.
5. Files: Products_<scope>_new_descriptions_matrixify.csv with columns ID, Handle, Command (UPDATE), Body HTML (new leading part followed by the preserved blocks); Products_<scope>_ROLLBACK_original_descriptions_matrixify.csv (current descriptionHtml); REVIEW_<scope>_descriptions_verify_notes.csv (Handle, Title, Words, Verify notes, Sources), with the most important unconfirmed items starting "PRIORITY:".
